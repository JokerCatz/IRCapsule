# IR Capsule

[English](README.md) | [繁體中文](README.zh-TW.md) | **简体中文**

用 ESP32-C3 做的红外中继器，也能当蓝牙电视遥控器。它学习你现有遥控器的信号（电视、机顶盒、空调……），
保存起来，需要时再发射。计划装在透明扭蛋壳里，通过蓝牙（BLE）用静态网页设置和操作；可以从网页触发，
也可以用一个“家电不会理会”的备用红外遥控器触发。

> **状态：可运行的原型。** 硬件已经做好，主要功能可用；部分实际使用场景还没有确认。请看[当前状态](#当前状态)。

## 工作方式

```
备用遥控器（家电不会理会的代码） ──红外──▶ [VS1838B ×1–4] ─┐
                                                           ▼
                 手机／电脑 ──蓝牙（Web Bluetooth）──▶  ESP32-C3 Super Mini ──蓝牙遥控器──▶ Android / Google TV
                                                           │ GPIO5
                                                           ▼
                                       [ULN2003] ─▶ [IR333C-A 环形 ×8] ──红外──▶ 家电
```

- **录制：** 接收头可以接收任何遥控器；每条信号按原始的高低电平时长保存，并附上对协议的推测。
- **重放：** 用硬件产生 38 kHz 载波（ESP32-C3 的 RMT 外设）发射原始时序，蓝牙中断不会干扰载波。
- **触发：** 网页上你自定义的按钮，或备用遥控器的代码。胶囊只响应列表里的代码，并忽略自己发出的光，
  所以不会自己触发自己。
- **输出：** 向家电发射红外信号，或通过蓝牙向已配对的电视发送按键。
- 设备上没有网页服务器、不用 Wi-Fi、不用 SD 卡。所有数据保存在芯片的 4 MB 闪存里。

## 蓝牙电视遥控器

对于没有红外代码的电视功能，胶囊可以和 Android / Google TV 配对成蓝牙遥控器（HID over GATT）。作者在一台
TCL Android 电视上确认可用：方向键、确定、返回、主页、输入源、电视设置、音量、播放控制、YouTube、Netflix
和电源（关机）。快退／快进在那台电视上没有反应；其他按键尚未测试。不要指望能把电视从待机状态唤醒。

**关于蓝牙识别码：** 胶囊固定上报 **Google 参考遥控器**的厂商／产品识别码（`0957:0001`），因为 Android 按这组
识别码选择按键映射表
（[`Vendor_0957_Product_0001.kl`](https://android.googlesource.com/platform/frameworks/base/+/main/data/keyboards/Vendor_0957_Product_0001.kl)）。
本项目不是 Google 产品，未经 Google 认证，也不应带着这组识别码作为商品出售。它无法通过电视用来配对
原厂遥控器的界面：请使用普通的蓝牙配件列表。

配对方法：网页 → **设备** → **配对电视（120 秒）**，然后在 120 秒内到电视上添加胶囊。一定要先按按钮再配对。
重启和普通的 `idf.py flash` 之后，配对仍然有效。

## 自定义遥控器与转发

* **遥控器**标签页：胶囊上最多保存 8 个遥控器，每个 3 列、最多 12 行。每个按钮可以设置名称、32 种颜色之一，
  以及动作：电视按键（短按或长按）、已保存的红外信号，或“运行规则”（没有触发信号的规则可以当宏使用）。按钮可以
  设置按住连发，间隔 150–1000 毫秒。
* **转发规则**：接收头收到实体遥控器的信号后依次执行步骤：发射红外、等待、切换图层、**发送电视按键**。
  按一次执行一次；按住不会重复执行。

## 访问 header（建议设置）

不设置时，蓝牙范围内的任何人都能使用胶囊。可以在网页（**设备** → **蓝牙访问**）或通过 USB 设置。设置后，
网页要证明自己知道 header，之后所有传输都会加密（AES-GCM）；header 本身不会传输。网页会提供给 **NFC 标签**用的
网址，例如 `https://…/#h=<header>&n=<蓝牙名称>`：打开它就会自动填入 header（`#` 后面的部分不会发送到网页服务器；
浏览器可能把它保留在历史记录里）。Web Bluetooth 仍然需要点一下**蓝牙**并选择设备。USB 永远不需要 header，
也可以用来重置。

它防不了的事：拿到 header 或标签的人可以进入；太短或容易猜的 header 可能从录下的传输内容中猜出（请使用网页
提供的 22 个随机字符）；以后 header 泄露，之前录下的内容也能解开；在还没有设置 header 的蓝牙连接上设置它，
那一次是不加密传输；它也无法阻止扫描、占用连接、配对或干扰。如果不想太显眼，可以给胶囊起自己的蓝牙名称；
本项目的服务代码不会广播，但电视遥控器服务必须广播。

## 备份与还原

在**设备**标签页。**导出备份**会把信号（包括草稿）、波形、规则、设备分组、自定义遥控器和设置（名称、忽略重复的
时间、图层）保存为一个 JSON 文件。**从备份还原会覆盖**胶囊上的内容：先检查文件、下载当前数据、请你确认，写入后
再读回比对。如果中途断开连接，重新导入同一个文件即可。电视配对、访问 header 和草稿的录到次数不在备份里。修改的
名称要重启后才生效。

## 硬件

| 元件 | 数量 | 备注 |
|---|---|---|
| ESP32-C3 Super Mini | 1 | 4 MB 闪存，板载 LED 在 GPIO8 |
| VS1838B 红外接收头 | 1–4 | 用 3V3 供电，绝对不要接 5V。输出并联到 GPIO4 |
| IR333C-A 940 nm LED | 8（另备 4） | 4 串，每串 2 颗串联 |
| ULN2003APG（DIP-16） | 1（另备 1） | 不能用 ULN2004：它的输入需要 6–15 V |
| 22 Ω 电阻 | 4 | 每串一个 |
| 100 µF 电解电容 | 1 | 接在 5V 上（+ 接 5V），在 LED 脉冲时稳定供电 |
| 0.1 µF 陶瓷电容（标记 104） | 每个接收头 1 个 | 接在每个 VS1838B 的 VCC 与 GND 之间。ULN2003 旁可以再加一个（选配） |

完整电路图、引脚表、环形布局和上电前检查：**[docs/wiring.html](docs/wiring.html)**（用浏览器打开，英文）。使用的引脚：

| GPIO | 功能 |
|---|---|
| 4 | 红外接收（VS1838B OUT，空闲时为高电平） |
| 5 | 红外发射（ULN2003 IN1–IN4） |
| 8 | 板载状态灯（不是外接元件） |

**焊接后检查 LED：** 连上网页，打开**设备**标签页，点**开始 LED 测试**（协议命令 `ledtest`）。所有发射 LED 会闪烁
60 秒，用手机相机观看。每一串是两颗串联，所以只要一颗损坏或接反，那一串的两颗都不会亮。

## 编译与烧录

需要 [ESP-IDF](https://docs.espressif.com/projects/esp-idf/) v6.1。

```sh
cd firmware
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash        # C3 的 USB-Serial/JTAG 串口，不需要按 BOOT 键
```

如果同时接了多块开发板，建议使用固定的 `/dev/serial/by-id/...` 路径。用 esptool 或 pyserial 打开某块板子的串口
可能让它重启，和其他项目共用一台电脑时要小心。

## 网页设置界面

`web/index.html` 是单个静态文件。由于 Web Bluetooth 需要安全环境，请通过 HTTPS（GitHub Pages 即可）或
`http://localhost` 提供。

```sh
cd web && python3 -m http.server 8000      # 然后打开 http://localhost:8000
```

Android 或电脑上使用 Chrome 或 Edge。iPhone 请使用支持 Web Bluetooth 的浏览器，例如 Bluefy。Web Serial（USB）需要
电脑版 Chrome 或 Edge。网址加上 `?demo=1` 可以用模拟的胶囊试用。

一般使用流程：

1. **录制**（**红外信号**标签页）：点**开始录制**，然后拿任意遥控器对着接收头按键。每个新按键会成为一条带编号的
   草稿并附带波形；重复按同一个键只会增加次数。**试发**可以立即发射草稿。
2. **命名**：输入名称（或粘贴列表，每行一个，按录制顺序套用），选择类型和设备分组，点**保存已命名的草稿**。
   只有命名过的信号才能用在按钮和规则里。
3. **发射**：在**红外信号**标签页，或使用**遥控器**标签页上你自定义的按钮。
4. **转发规则**：**当收到**某个已保存的信号（例如备用遥控器的一个键），**则执行**一串步骤。规则和信号可以停用而
   不必删除。
5. **设备**：电视配对、蓝牙访问 header、备份、设置、LED 测试和设备记录。

## 命令行工具

开发用。需要 [pyserial](https://pypi.org/project/pyserial/)；部分工具还需要 `bleak`、`websockets` 或 `cryptography`。
工具的输出和说明是英文。

```sh
export IRCAP_PORT=/dev/serial/by-id/usb-Espressif_USB_JTAG_serial_debug_unit_<MAC>-if00

python3 firmware/tools/selftest.py          # 录制、命名、发射、规则、保存；保留你的数据
python3 firmware/tools/relay_check.py       # “按一次执行一次”与电视按键规则步骤
python3 firmware/tools/ui_check.py          # 遥控器布局存储（需要两个空位）
python3 firmware/tools/ledtest_check.py     # LED 测试命令
python3 firmware/tools/burst_check.py       # 连续发送多条命令
python3 firmware/tools/access_check.py      # 访问 header 与加密（USB 加上这台电脑的蓝牙）
python3 firmware/tools/remote_check.py      # 电视遥控命令。警告：会忘记已配对的电视
python3 firmware/tools/bridge.py 8765       # USB <-> WebSocket，用来测试网页
python3 firmware/tools/capture.py "$IRCAP_PORT" captures/tv.jsonl 60 tv   # 把原始信号记录到文件
```

这些工具大多会暂时发射红外信号或改动已保存的数据；运行前请先阅读工具开头的说明。范围内已配对的电视会自己连回来，
所以任何发送电视按键的操作都会真的控制它。`securelink.py` 是加密蓝牙协议的参考客户端。

通信协议见 [docs/protocol.md](docs/protocol.md)（英文）。打开串口会让开发板重启，所以插上后请等几秒再运行工具。

## 已知限制

- VS1838B 会解调信号，因此无法测出被录遥控器的载波频率。重放默认 38 kHz；其他载波（36、40、56 kHz）需要手动设置。
- RMT 的时长是 15 位，超过 32 767 µs 的项目在发射时会拆成多段。
- 静默 30 毫秒后视为一条信号结束（1 MHz 下的硬件空闲上限），所以内部间隔较长的空调信号会分成几条收到。
  可以用 `gap` 字段把它们归在一起。
- **空调每次都发送整个面板状态**（模式、温度、风量……）。因此录下的信号会把家电设置成录制时的状态。需要几种状态
  就分别录几条（例如“空调 26 °C”、“关机”）。目前没有实现单独调整某个字段（升温／降温）。
- 开机后可用内存约 73 KB（含蓝牙协议栈）。可保存 96 个信号和 48 条规则，每个信号最多 1200 个项目；限制在内存，
  不是闪存。
- 没有设置访问 header 时，蓝牙范围内的任何人都能连接、修改设置、向已配对的电视发送按键，并打开配对时间。蓝牙配对
  本身一律接受（Linux 主机需要），但按键只发送给在配对时间内选定的电视。
- 只录制和重放你拥有或有权控制的设备的遥控信号。
